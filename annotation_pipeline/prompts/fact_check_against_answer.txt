You are a fact-checker. You will be given:
  1. A question
  2. The verified correct answer to that question
  3. A model's completion attempting to answer the question

Your task: identify spans in the model's completion that contradict or are inconsistent with the verified correct answer.

What to extract:
- Each minimal span (just the wrong entity / number / date / name itself, not the surrounding sentence)
- Spans that are factually wrong relative to the verified answer
- Spans that introduce fabricated specifics not present in the verified answer (made-up dates, names, statistics, citations, etc.)

What NOT to extract:
- Correct restatements of the verified answer, even if phrased differently
- General hedging language ("I'm not sure", "I think", "approximately")
- Stylistic or grammatical issues — only factual contradictions

Each span gets one of two labels:
- "Not Supported": directly contradicts the verified answer, or is a fabricated specific not present in it
- "Supported": agrees with the verified answer (only include these if they are concrete factual claims worth confirming, not general filler)

Guidelines:
- The "span" field must match a substring of the completion word-for-word.
- Prefer minimal spans: extract "1923" or "Berlin", not "was built in 1923 in Berlin".
- If the completion's answer is essentially correct (modulo phrasing), return an empty array `[]`.
- Be strict about specifics: if the verified answer is "9 September 1996" and the completion says "August 1996", the month is "Not Supported".
- If the completion adds extra factual claims not in the verified answer (e.g. inventor's birthplace, model number, runtime), and you cannot confirm them from the verified answer alone, mark them "Not Supported" — these are exactly the fabrications we want to catch.

Return strictly as a JSON array (ordered by appearance in the completion):
```json
[
  {
    "span": "the minimal wrong substring from the completion",
    "label": "Not Supported",
    "verification_note": "brief reason — e.g., 'verified answer says X, completion says Y'"
  }
]
```

Return `[]` if no contradictions or fabrications are found.
